### C.3 활용신청 화면의 위치기반서비스사업자 안내 (사용자가 붙여준 안내문)
- 안내문은 위치정보를 포함한 공공데이터를 쓰는 사업자에게 방송통신위원회 허가·신고와 필증 첨부를 요구하며, 해당하는데 필증이 없으면 반려될 수 있다고 한다.
- 이 API의 설명문에 좌표·주소 기반 항목이 나오지 않으므로 필증 첨부 대상이 아닐 가능성이 높다 — **법률 판단이 아닌 해석**이며 확신이 없으면 포털 안내에 문의.
- 이후 병원 정보처럼 좌표가 들어 있는 API로 '가까운 병원 찾기'를 만들 때는 위치정보법 해당 여부를 따로 확인해야 한다.

## D. RxNorm·ATC 기술 조사 (사전 시드)
`[관찰]` — https://rxnav.nlm.nih.gov/REST 를 인증 없이 호출해 확인.
- 성분(IN) 개념의 속성에 **RxCUI·ATC·SNOMED CT 개념 ID**가 함께 있다(예: 오메프라졸 RxCUI 7646 → ATC A02BC01).
- **ATC는 성분당 여러 개**일 수 있다(이부프로펜 5개, 프레드니솔론 11개). 검증은 "어느 하나와 일치"로 판정해야 한다.
- 성분에 ATC가 없을 때(레보티록신) 염(PIN) 개념에서 보완할 수 있다.
- ATC 상위 분류(1~4단계 이름·경로)는 RxClass `classContext`로 얻는다.
- 성분 → 제형·함량(SCD)·제품(SBD)은 `related.json?tty=SCD+SBD`. SCD 이름 문자열에서 함량·제형을 파싱했고, 복합제는 제외했다.
- VMP/AMP는 **미국 RxNorm 기준**이라 국내 허가 규격과 다를 수 있다. 단위용량 검증은 "미국 규격에 있는가"만 의미한다.
- 사전 규모(이 프로토타입): 성분 32 · VMP 516 · AMP 410.
- SNOMED CT 개념 ID는 RxNorm이 돌려준 값을 그대로 담았다. 사용 조건은 SNOMED 라이선스(한국은 회원국)를 따른다 — 약어·ID 자체의 이용 범위는 확인하지 않음 `[미확인]`.

## E. 환각 제어·검증 설계 조사 결과
- 사후 검증(결정론적 규칙)이 잡는 것: 사전의 코드·계열·RxCUI·단위용량과의 불일치. 못 잡는 것: 사전에 없는 내용의 사실 여부, 임상적 적정성.
- **사전에 없는 약물명 탐지**는 INN 어간 규칙만으로는 약하다 — 독립 보류 세트 34개 중 11개(32%, 95% CI 19–49%). 근본 해법은 MFDS 성분명 전수 목록.
- 합성 문장 벤치마크는 단위 테스트일 뿐이며, 실제 LLM 답변에서 합성으로는 안 나온 거짓 경보 3건이 발견되었다(04 문서).
- 계획서의 3개 비교 조건(일반 LLM / 사전 연동 / 온톨로지+검증)을 돌리려면 **실제 LLM 답변과 약사의 정답 라벨**이 필요하다. 파일럿(04 문서)은 그 대체물이 아니다.

## F. 작업 환경에서 확인한 제약 `[관찰]`
- `apis.data.go.kr`는 조직 관리자의 허용 목록 밖이라 접근 요청이 거부되었다(승인으로 해제 불가). MFDS 수집은 사용자 PC에서 `tools/fetch_mfds.mjs`로 수행한다.
- 이 환경에는 예약·반복 실행 기능이 없다. 일일 한도 이어받기는 사용자 PC의 작업 스케줄러용 `tools/run_mfds_resume.cmd`로 대신한다(등록 절차는 시험하지 못함).
- 인증키는 채팅·파일·산출물에 두지 않고 사용자 PC의 `.env`에만 둔다.

## G. 미확인 항목과 권장 후속 조사
1. 방준석 등(2026) 문헌의 서지 확보, OntoPharma의 병원명·알림 속도 원문 확인.
2. MFDS 08 오퍼레이션의 실제 응답 필드명(첫 실행 출력으로 확인), 오류 코드 의미, 의약품안전나라의 ATC·주성분 영문명이 API에 있는지.
3. 대한약학회 약학용어집·약학정보원 사전의 기계가독 제공 여부와 이용 허락.
4. RAG·환각 완화에 관한 동료심사 문헌(벤더 문서 대체).
5. DUR 오픈API의 구조와 용량·병용 규칙의 사전 연동 가능성.
6. 위치정보법 해당 여부(병원 위치 API를 쓰는 기능을 만들 때).
