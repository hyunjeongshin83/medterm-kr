## ③ 인증키 저장
프로젝트 폴더의 `.env` 파일에 한 줄만 적는다(따옴표·공백 없이). **인증키를 채팅에 붙여넣지 않는다.**
```
DATA_GO_KR_KEY=<여기에 인증키>
```
이 환경은 `apis.data.go.kr`에 접속할 수 없어(관리자 허용 목록) Credentials 등록은 쓸 수 없다.

## ④ 수집 실행 (Node 20.6 이상)
```
node --env-file=.env tools/fetch_mfds.mjs --out "C:\Users\<사용자>\Downloads\mfds_out"
```
- 기본 서비스는 `DrugPrdtPrmsnInfoService08`. 오퍼레이션 이름이 다르면 `--list-op`, `--ing-op`으로 지정한다.
- 일일 호출 한도(개발계정 10,000회)에 걸리면 진행 상태가 저장되며 다음 날 같은 명령으로 이어받는다.
- 끝나면 출력되는 **"첫 레코드 필드" 줄**과 완료 사실을 알려준다. 오류 시 "중단:" 뒤 메시지만 전달하면 된다(메시지에 키는 들어가지 않는다).
- 매일 자동으로 이어받으려면(선택) 사용자 PC에서:
  `schtasks /Create /SC DAILY /ST 09:10 /TN MedTermMfdsFetch /TR "\"<프로젝트 경로>\tools\run_mfds_resume.cmd\"" /F` — 해제: `schtasks /Delete /TN MedTermMfdsFetch /F` (등록 절차는 이 환경에서 시험하지 못했다).

## 확인되지 않은 것
- 수집 스크립트는 모의 서버로만 시험(17/17)했다. 실제 MFDS 08 응답의 필드명·오류 코드는 첫 실행으로 확인한다.
- 온톨로지는 rdflib로 다시 읽어 SPARQL로 확인했으며 Protégé에서 열어 보지는 않았다.
- ⑧~⑩은 약사, 서버 프록시, 실제 LLM 답변과 정답 라벨이 있어야 하며 에이전트가 대신 만들 수 없다.
