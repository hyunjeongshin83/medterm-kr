# 파일럿 실험 결과 (실제 LLM 답변)

작성일 2026-11-03 · 모델 (model id withheld) · 답변 104개 · 상세 설계와 해석은 02 문서 §8

**정답 라벨이 없는 파일럿이다.** 판정은 비전문가(본 에이전트)가 원문을 읽고 했고 판정자 LLM이 보조했다. 약사 판독이 아니다. 가짜 이름 8개는 '실존하지 않을 가능성이 높음'일 뿐 미검증이다. 같은 질문을 두 번(v1, v2) 돌렸고 v2는 v1 결과를 보고 고친 뒤라 독립 평가가 아니다.

## 설계
- 질문: "…의 ATC 코드, 약물 계열, 흔한 단위 용량(mg)을 알려주세요."
- 조건 A: 일반 프롬프트 / 조건 B: 사전 근거 주입 프롬프트(`medterm prompt`)
- 유형: 사전 내 실존 약물 32개, 가짜 이름 8개, 사전 밖 실존 약물 12개(조건당)

## 결과 (모든 수정 적용 후 재검증)
| 질문 유형 (조건당 n) | 일반(A) | 근거 주입(B) | 해석 |
|---|---|---|---|
| 사전 내 실존 약물 (32) | 검증기 표시 0 | 검증기 표시 0, 사전 ID 인용 32/32 | 흔한 약이라 일반 조건도 오류가 없었다 — 근거 주입의 정확도 이점은 측정되지 않음(천장 효과) |
| 가짜 이름 (8) | 환각·대체 2/8 (95% CI 7–59%) | 0/8 (95% CI 0–32%) | Fisher 정확검정 p=0.467 — 통계적으로 유의하지 않음 |
| 사전 밖 실존 약물 (12) | 정보 제공 12/12 | "사전에 없음" 12/12 (1건은 일반 지식을 덧붙임) | 근거 주입의 비용: 사전이 32개 성분뿐이라 범위 밖 질문에 도움이 안 됨 |

가짜 이름 일반 조건의 2건: 카도올롤을 카르테올롤로 바꿔 답하면서 알리지 않음(대체), 라도프라졸을 PPI로 소개하며 10·20mg 용량 제시(환각).

## 실제 답변에서 드러난 검증기·프롬프트 결함 (수정함)
| 번호 | 현상 | 수정 | 남은 부작용 |
|---|---|---|---|
| 1 | "비스테로이드성 소염제" 속 "스테로이드"를 코르티코스테로이드 계열 주장으로 읽어 거짓 오류 | 앞 글자가 "비"이면 제외, NSAID 별칭 추가 | 없음(진짜 스테로이드 오류는 계속 탐지) |
| 2 | "페니실린 계열" 등 계열명을 미등록 약물명으로 경고 | 계열명 허용 목록 | 약물명이자 계열명인 용어('페니실린')는 경고하지 않음 |
| 3 | "복합제는 다른 ATC 코드(C09DA03…)"라는 문장을 코드 불일치 오류로 처리 | 복합제 맥락은 '정보(검증 불가)'로 낮춤 | 같은 문장에 "복합"이 있으면 진짜 코드 오류도 오류로 올리지 않음 |

실존 약물 답변에서 표시된 3건은 모두 검증기의 거짓 경보였고 진짜 오류는 관찰되지 않았다.
