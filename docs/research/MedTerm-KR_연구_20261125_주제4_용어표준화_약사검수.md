## 개선안 (모두 가설·미측정)
1. **자동 점검 5차원 먼저**: 검증성·유일성·완전성·일관성·적시성을 `tools/` 점검 스크립트로 건수 보고하고 약사는 정확성만. 검증: `data/medterm_ext_review.tsv` 400개에서 자동 점검이 잡은 항목이 약사 X 판정의 몇 %인지.
2. **검수 운영 규칙서와 판정 필드**: 안내서에 지침서 → 연습 라운드 → 독립 판정 → 일치도 → 조정 → 승인 확인 순서를 쓰고, 시트에 `reviewer_id`(가명)·`reviewed_at`·`reason`·`adjudicated_by` 열 추가(초안). 조정 규칙은 출처에 없어 직접 정해야 함.
3. **제품명 성분 병기를 보조 단서로**: 국내 제품 58,178건에서 괄호 병기 패턴 건수를 세고 무작위 50건을 일반명코드 성분과 대조. 자동 연결에는 쓰지 않음. 한계: 규정 원문·시행일 미확인, 시행 전 허가 품목·한약제제 제외, 염·수화물 생략 가능.
