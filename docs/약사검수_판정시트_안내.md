# 약사 판정 시트 안내 (MedTerm-KR 확장 수록)

> 약사 검수 전 초안의 연결이 실제로 맞는지 재는 시트입니다. 판정 값은 사람이 적으며, 도구는 판정을 만들어 내지 않습니다.

## 1. 무엇을 재는가

자동으로 만든 연결(미국 RxNorm 성분 ↔ 심평원 일반명)이 맞는지 **약사 2명이 따로** O / X / ? 로 판정하고, (가) 자동 연결이 맞다고 본 비율, (나) 두 사람의 일치도(κ)를 계산합니다. 연구 개선안 2("매핑 등급별 약사 판정 일치율")의 검증 도구입니다.

| 파일 | 내용 | 행 |
|---|---|---|
| `data/review/상용상위100_판정시트.csv` | 심평원 **단일성분 등재 품목 수**가 많은 순 상위 100 성분. 등급은 a 80 · b 8 · d 12 | 100 |
| `data/review/등급b_층화100_판정시트.csv` | 등급 b(이름만 일치, ATC 근거 없음) 1,278개 중 100개. 절반은 이름이 정확히 같은 연결, 절반은 염·수화물·약어 규칙으로 맞춘 연결(무작위, 시드 1) | 100 |
| `data/medterm_ext_review_shared_cd.tsv` | 심평원 일반명코드 **앞 4자리**가 둘 이상의 항목에 걸린 목록 60건 — 사람이 보는 단서(5절) | 60 |

- 시트를 둘로 나눈 이유: 상용 상위 100 에는 등급 b 가 8개뿐이라 b 의 정확도를 따로 재야 합니다.
- '상용'은 심평원 등재 품목 수로 가른 대리 지표이며 처방량이 아닙니다. 상용 상위 표본은 많이 등재된 성분에 쏠려 있어 전체 자료의 정확도를 대표하지 않습니다.
- 약사에게 가는 시트에는 시스템의 **연결 등급·규칙을 싣지 않았습니다**(판정이 거기에 끌리지 않도록). 분석할 때 도구가 성분ID 로 `data/medterm_ext.json` 에서 불러옵니다.

## 2. 약사님께 — 판정하는 법

1. 시트를 엑셀로 열고 **판정A**(첫째 약사) 또는 **판정B**(둘째 약사) 칸에 `O`, `X`, `?` 중 하나만 적습니다. 서로의 판정은 끝날 때까지 보지 않습니다(독립 판정).
2. 한 행의 질문은 **RxCUI 칸**에 따라 다릅니다.

| RxCUI 칸 | 질문 | O | X | ? |
|---|---|---|---|---|
| 값이 있음 (미국 RxNorm 성분과 연결됨) | '이름(영문)'과 '다른 영문 표기'에 적힌 이름들이 **모두 같은 성분**(염·수화물·표기 차이만)인가? | 같다 | 다른 성분이 섞여 있다 — 메모에 어느 이름인지 | 모르겠다 |
| 비어 있음 (RxNorm 과 연결 안 됨) | **미국 RxNorm 에 대응 성분이 없다**는 판단이 맞는가? | 맞다(대응 없음) | 대응 성분이 있다 — 메모에 RxNorm 영문 이름 | 모르겠다 |

3. 염·이성질체 때문에 약이 달라지는 경우(예: d-/l- 형)는 `X` 로 적고 메모에 이유를 씁니다.
4. 참고 칸(한글명 후보 · ATC · 품목 수 · 일반명코드 · 코드 앞 4자리가 같은 다른 항목 · 비슷한 이름)은 판단을 돕는 자료입니다. **한글명이 맞는지는 이 시트에서 판정하지 않습니다**(필요하면 메모에 적기).
5. 저장: 엑셀에서 **CSV UTF-8(쉼표로 분리)** 로 저장합니다(한국어 엑셀의 기본 CSV 도 읽힙니다). 약사 이름·연락처는 시트에 적지 않습니다.

## 3. 대표님께 — 계산하는 법

```
python -I tools/review_agreement.py 약사A.csv 약사B.csv --md 일치도보고.md
```

- 한 사람이 판정A 만, 다른 사람이 판정B 만 채운 파일 둘을 같이 주면 성분ID 로 합칩니다. 한 파일에 두 칸이 다 있어도 됩니다.
- 보고서: 층별(등급 a · b 정확 일치 · b 규칙 연결 · d) 일치율·κ(PABAK 병기), 자동 연결이 맞다고 본 비율(약사별 Wilson 구간), 합의 기준 범위(하한 = 둘 다 O, 상한 = 둘 다 O + 의견 갈림), 규칙 묶음별 비율, 따로 볼 행(X 가 있거나 의견이 갈린 행), 입력 점검(알 수 없는 값·충돌·중복·자료에 없는 ID).
- 읽을 때 주의: κ 는 한쪽 값(대개 O)에 쏠리면 일치율이 높아도 낮게 나옵니다 → 일치율·PABAK 을 같이 봅니다. 쌍이 20개 미만인 층은 참고용이며 구간은 근사입니다. 의견이 갈린 행은 세 번째 약사나 협의로 정하면 범위가 한 점으로 좁혀집니다.
- 결과 활용: 규칙으로 맞춘 b(`b 규칙 연결`)에서 X 가 모이는 규칙이 있으면 `build/ext_norm.py` 의 해당 규칙을 고치고 `python -I tools/norm_rules_table.py` 로 규칙표(`docs/염_정규화_규칙표.md`)를 다시 만듭니다.

## 4. 시트를 다시 만드는 법

```
python -I tools/review_sheet.py --shared data/medterm_ext_review_shared_cd.tsv
python -I tools/review_sheet.py --mode b-strat
```

같은 자료·같은 옵션이면 같은 시트가 나옵니다. 자료 버전이 바뀌면 성분이 달라질 수 있으므로 **시트를 새로 만든 뒤 판정**하세요(분석 도구가 자료에 없는 성분ID 를 알려 줍니다).

## 5. 코드 앞 4자리 목록을 어떻게 보나

원자료에서 확인한 사실입니다.

- 심평원 일반명코드 9자리 = 6자리 번호 + 투여 구분 1자리(A 내복 · B 주사 · C 외용 · D 기타) + 제형 2자리. 투여 구분은 원자료 59,631행 중 59,619행에서, 제형 2자리는 전 행에서 해당 열과 일치했습니다.
- 번호는 성분 식별자가 **아닙니다**. 같은 약이 여러 번호를 쓰고(thiopental sodium: 2376 · 3135 · 3942 · 4822), 다른 약이 같은 번호를 씁니다(예: 193801 — metoclopramide 와 metoprolol, 611901 — peramivir 와 indacaterol).
- 그래서 코드로 성분을 자동으로 합치지 않습니다. 데이터에는 단일성분 일반명코드 **전체(9자리)** 를 `hira_codes` 로 기록해 원자료의 행을 되짚는 용도로만 씁니다.
- 앞 4자리가 겹치는 60건에는 같은 성분의 표기 차이로 보이는 쌍(예: cyclosporine / cyclosporin, hypromellose / hydroxypropylmethylcellulose)과 전혀 다른 약이 섞여 있습니다. 약사가 보고 동의어로 묶을 것만 골라 규칙표나 동의어 목록에 반영하는 **단서 목록**입니다.

## 6. 한계

- 이 시트의 판정은 이름·ATC·코드 정보로 하는 것이며 임상 판단이 아닙니다. 판정 결과가 나와도 자료는 약사 검수 전 초안이라는 표시(`review_status=draft`)를 바꾸지 않습니다 — 검수 완료로 올리는 기준은 별도로 정해야 합니다.
- 표본이 100개이므로 층별 구간이 넓습니다. 등급 d 는 12개뿐입니다.
- 한글 이름·상품명·링크의 정확성은 이 시트에서 재지 않습니다(7절의 두 시트가 그 용도입니다).

## 7. 이름·상품명 대조 시트와 약사법 풀이 검토 시트 (v1.5.0 · 앱 판정은 v1.6.0)

판정 시트(1~5절)가 자동 *연결*을 재는 것이라면, 이 두 시트는 **사전에 적힌 말**이 맞는지 약사가 눈으로 확인하는 용도입니다. 검수를 세 단계(① 자료 대조 → ② 약사 확인 → ③ 약사 검수 완료)로 나누어 표시할 때 ②의 입력이 됩니다. 앱의 ‘데이터·한계’ 탭 ‘검수 상태’에 같은 3단계가 있습니다.

| 파일 | 내용 | 행 |
|---|---|---|
| `data/review/핵심_성분_상품명_대조시트.csv` | 핵심 성분 한글명 32 + 국내 상품명 28. 약사가 약학정보원 화면을 열어 놓고 사전 표기와 같은지 O / X / ? 표시 | 60 |
| `data/review/약사법_쉬운풀이_검토시트.csv` | 약사법 쉬운 풀이 53개. 법령 원문 발췌와 풀이가 맞는지 O / X / ? 와 수정 제안 | 53 |

- 만드는 법: `python -I tools/make_check_sheets.py` (저장본이 지금 자료와 같은지만 보려면 `--check`). 자료 파일만 읽고 네트워크를 쓰지 않습니다. 같은 자료면 같은 파일이 나옵니다.
- 약학정보원 화면은 도구가 가져오지 않습니다. 약사가 일반 이용자로 화면을 열어 놓고 O / X / ? 만 적으며, 화면의 내용을 복사해 오지 않습니다(누리집이 허락 없는 복제·배포·전송·변경·게시를 금하고 있습니다). 이용 문의에 대한 답이 오면 이 절차를 갱신합니다.
- 도구의 판정은 싣지 않았습니다(약사가 도구 결과에 끌리지 않도록). 확인자·확인일은 약사가 직접 적고, 약사 이름·연락처를 미리 적지 않습니다.
- 성분 한글명·상품명은 1차 원본(심평원 약가마스터·위키데이터)과 이미 대조했습니다(2026-11-06). 약학정보원은 이를 편집한 2차 자료라 ‘독립된 두 번째 출처’로 가치가 있지만 1차 원본을 대신하지는 않습니다.
- 약사법 쉬운 풀이는 법제처 출력본 본문과 대조했습니다(원문 대조). 이 시트는 약사가 풀이의 쉬움과 정확함을 보는 용도이며 법률 검토가 아닙니다.
- **앱에서 직접 판정하는 길이 v1.6.0 에 생겼습니다.** 약사가 앱의 ‘데이터·한계’ 탭 ‘약사 검수 참여’(또는 주소 끝 `#review`)에서 이 두 시트와 같은 항목(60 + 53)을 판정하고 확인서를 내면, 운영자가 면허를 확인한 뒤 `tools/merge_pharmacist_reviews.py` 로 합칩니다. 절차는 `docs/약사검수_참여_안내.md` 에 있습니다. 엑셀 시트로 받은 판정을 합치는 도구는 없습니다(시트로 받았다면 앱에서 다시 입력하게 하거나, 필요할 때 변환 도구를 만듭니다). 합치기 전에는 모든 항목이 ‘약사 검수 전 초안’입니다.
