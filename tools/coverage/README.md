# 수록 범위 표본 점검 (coverage probe)

- **하는 일**: 공개 API(NLM RxNav, PubChem PUG REST)에 성분 영문명을 한 개씩 조회해 "RxNorm에서 성분(IN/PIN/MIN)으로 잡히는지 · ATC 분류가 붙는지 · PubChem에서 화합물로 잡히는지"만 확인합니다. 대량 수집이 아닙니다(이름 54개, 초당 4회 안팎).
- **실행**: `node tools/coverage/probe.mjs` (Node 18 이상, 인터넷 필요). 결과는 같은 폴더의 `results.json` 을 덮어씁니다. `probe.log` 는 2026-11-03 실행 때의 화면 출력입니다.
- **표본**: 벤치마크 보류2의 사전 밖 실존 약물 34개 + 한국 상용 성분 예시 17개(미국 허가 약이 아닌 것으로 알려진 예, **대표성 없음**) + 대조군 3개. 영문명은 이 점검에서 사람이 붙인 것이며 약사 검수 전입니다.
- **결과(2026-11-03)**: 보류2 34개 — RxNorm 성분 34/34(ATC 연결 33/34), PubChem 29/34(항체의약품 5개 없음). 한국 상용 예시 17개 — RxNorm 성분 10/17, PubChem 17/17. 대조군 3개 — 모두 잡힘.
- **한계**: 이름 일치만 봅니다. 국내 허가 여부 · 제형 · 함량 · 국내 상품명은 보지 않습니다. 표본이 작고 대표성이 없어 "수록 가능 비율"로 읽으면 안 됩니다.
- 약학정보원(health.kr) 등 이용 조건이 있는 사이트는 조회하지 않습니다. 배경: `docs/research/05_수록범위확대_DB조사_20261103.md`.
