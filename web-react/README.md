# MedTerm-KR React 화면 (web-react)

화면(큰 화면은 분류 트리 · 작업 탭 · 상세의 3단, 휴대폰은 한 줄 화면 + 하단 탭)을 **React 18 · Tailwind CSS 3 · React Flow(@xyflow/react 12)** 로 만든 소스입니다. 사전 데이터와 검증 로직(`../web/js/` 의 `medterm-data.js` · `bench.js` · `core.js`)은 그대로 쓰고 **화면만** 바꿨습니다. 연구·교육용 프로토타입이며 진단·처방·개인별 복용량 판단에 쓰지 않습니다.

## 결과물 (빌드하면 `dist/`에 생김 — 미리 만든 것도 함께 들어 있음)
| 파일 | 용도 |
|---|---|
| `MedTerm-KR_react.html` | 독립 실행. 더블클릭으로 열림(서버 불필요, 외부 요청 없음). 글꼴(Pretendard)은 파일 안에 담김. |
| `artifact.html` | 공유 페이지(웹 게시)용 조각: doctype·html·head·body 없음, 글꼴은 안에 담김(외부 글꼴 서버 접속 없음), 서버 프록시 입력 숨김. |
| `MedTerm-KR_app.html` | 설치형 안드로이드 앱(`../android-app`)용: 문서 전체, 외부 요청 없음(글꼴은 안에 담김), 서버 프록시 입력 숨김. 앱의 `assets/index.html` 로 복사해서 씁니다. |
| `pwa/` | **설치형 웹앱(PWA)** 폴더: `index.html`(독립 실행 화면에 설치용 태그만 더한 것) · `manifest.webmanifest` · `sw.js`(오프라인용 서비스 워커) · `icons/` · `.nojekyll`. 폴더째 https 서버의 어느 경로에 올려도 됩니다(경로가 모두 상대 경로). 아래 "웹앱(PWA)" 참고. |

`dist/tokens.css` · `dist/tw.css` 는 빌드 중간 산물이라 저장소에는 올리지 않습니다(`.gitignore`).

## 다시 만들기 (Node 22에서 확인)
```
cd web-react
npm ci
npm run build          # node build.mjs → dist/ 세 HTML + dist/pwa/ (웹앱 폴더)
```
`build.mjs` 는 기본으로 한 단계 위의 `../web/js` 를 읽습니다. 다른 폴더를 쓰려면 `MEDTERM_JS=<폴더> npm run build`.

## 웹앱(PWA)
같은 화면을 휴대폰·PC의 홈 화면/앱 목록에 설치하고, 인터넷이 끊겨도 열리게 한 판입니다(`dist/pwa/`).
- **열어 보기(내 PC)**: `python3 -m http.server 8080 --directory dist/pwa` 를 실행하고 크롬에서 `http://localhost:8080/` 를 엽니다. 주소창 오른쪽의 설치 아이콘(또는 메뉴 → 앱 설치)으로 설치합니다.
- **https 또는 localhost 에서만** 서비스 워커가 동작합니다. 같은 와이파이의 PC 주소(`http://192.168…`)로 휴대폰에서 열면 화면은 보이지만 설치·오프라인은 되지 않습니다. 휴대폰에 설치하려면 https 주소가 필요합니다.
- **오프라인**: 첫 방문 때 화면(사전 포함 `index.html` 한 파일)·설치 정보·아이콘 4개, 모두 6개 파일을 기기에 보관합니다. 이후에는 인터넷 없이 열리고, 열 때마다 뒤에서 새 판을 받아 두었다가 다음에 엽니다. 서비스 워커는 같은 주소의 GET 요청만 다루므로 서버 프록시(LLM 호출) 요청은 건드리지 않습니다.
- **새 판 반영**: 서비스 워커 파일의 버전이 화면·설치 정보·아이콘 내용의 해시(10자리)로 자동 정해집니다. 내용이 바뀌면 새 보관함이 만들어지고 옛 보관함은 지워집니다.
- **아이콘**: `pwa/icon.svg`(틸 바탕의 알약 — 안드로이드 앱 아이콘과 같은 모양) → `npm run icons`(크로미엄으로 PNG 4종 생성) → `pwa/icons/`. 모양을 바꿀 때만 다시 만들면 됩니다.
- 이 폴더를 어디에 올릴지(공개 주소)는 아직 정해지지 않았습니다. 비공개 저장소의 GitHub Pages 는 사이트가 **공개**되므로 정하기 전에는 켜지 않습니다.

## 점검
```
npm i --no-save playwright && npx playwright install chromium   # 처음 한 번 (package.json은 바뀌지 않음)
npm test               # tools/check_contrast.mjs + tests/ui.cjs + tests/artifact_wrap.cjs + tests/app_html.cjs + tests/pwa.cjs
```
- `tools/check_contrast.mjs` — 토큰의 글씨·바탕 색 짝 34쌍 × 라이트·다크를 WCAG 상대휘도로 계산해 글자 4.5:1 · 글자 아닌 것(그래프 선·입력 칸 테두리·초점 링) 3:1 에 못 미치면 실패(`npm test` 맨 앞).
- `tests/ui.cjs` — 실제 Chromium으로 214개 점검: 폭 1440/1280/1099/1024/768/700/699/390/360 가로 넘침 없음, 검색·상세·트리, 서랍 포커스·inert, 32개 성분의 그래프 노드·간선 수, 터치 가로 이동·세로 스크롤, 다크(바탕·글씨색이 토큰과 같음), 글꼴 4종이 외부 요청 없이 읽힘·켜진 탭 색·카드 모서리 20px·본문 15px, 콘솔 오류 0·외부 요청 0. **반응형 화면 구성**: 휴대폰(390)의 하단 탭(5개·44px 이상·접근 이름 유지)·검색 히어로(입력 48px)·분류 칩(개수가 사전과 같음, 눌러서 거르기)·카드 목록(12개씩 더 보기)·아래에서 올라오는 시트(바닥 붙임·위 모서리 20px·높이 88% 이하·Esc 후 포커스 복귀)·'관계 그래프 보기' 버튼 동작, 태블릿·노트북·데스크톱·와이드(768·1024·1440·1920)의 카드 열 수(1·2·2·3)와 서랍/3단 전환, 창 크기를 바꿔도 선택·검색 유지(700↔699 경계 포함), 다크의 하단 탭·히어로·카드 색.
- `tests/artifact_wrap.cjs` — `dist/artifact.html` 을 공유 페이지 바깥틀처럼 감싸 10개 점검(제목, 한 화면 맞춤, 주소 `#v-7646`, 글꼴이 외부 요청 없이 읽힘, 외부 요청 0; 데스크톱·휴대폰·다크)하고 화면을 `shots/` 에 저장.
- `tests/app_html.cjs` — `dist/MedTerm-KR_app.html` 을 휴대폰 폭(390·360)으로 열어 23개 점검(외부 글꼴·링크 없음, 5개 탭 모두 가로 넘침 없음, 면책 문구 원문, 검색·주소, 질의 탭에 프록시 입력칸 없음·안내가 "이 앱에서는", 모의 답변 검증, 다크, 콘솔 오류 0·외부 요청 0). 안드로이드 WebView 자체는 이 시험 대상이 아닙니다.
- `tests/pwa.cjs` — `dist/pwa/` 를 로컬 서버(`127.0.0.1`, 임의 포트)에서 열어 33개 점검: 파일·설치 정보(이름·id·상대 경로·아이콘 크기)·문서 태그·화면 코드가 독립 실행 판과 같음, 실제 크롬이 보고하는 설치 불가 사유 0건, 서비스 워커 등록·제어·보관함(파일 6개), 오프라인에서 새로고침과 `#v-7646` 주소 열기, 새 판이 올라오면 옛 보관함이 지워지고 교체됨, 휴대폰 390px 5개 탭 가로 넘침 없음, 데스크톱 1440px, 콘솔 오류 0·외부 요청 0. 캡처는 `shots/pwa/`. 실제 휴대폰에서 설치해 본 확인은 이 시험 대상이 아닙니다.
- 위 통과 수는 2026-11-04 작성 시점의 결과입니다(`ui` 214 · `artifact_wrap` 10 · `app_html` 23 · `pwa` 33 · 대비 68쌍). 데이터나 화면을 바꾸면 다시 돌려 보세요.

## 화면 구성(모바일 앱 템플릿식)과 반응형 (2026-11-04)
Figma 커뮤니티 "Mobile app UI Template" 의 **화면 구성(버튼·사진 자리·카드)** 을 따르되 **글꼴·글씨색·토큰 값은 그대로** 두었습니다(요청: "글씨는 괜찮습니다"). 값은 모두 `tokens.json`을 거치고 새 색은 추가하지 않았습니다(그림자 2종만 추가).
- **검색 첫 화면**: 알약 그림이 있는 옅은 틸 히어로 카드(질문 문구 · 높이 48px 검색 입력 · 지우기 버튼 · 예시 칩) → ATC 대분류 칩(눌러서 거르기, 숫자는 사전에서 계산) → 성분 카드 목록(썸네일 자리 · 이름 · ATC/RxCUI · 상태 배지, 12개씩 "더 보기").
- **상세**: 큰 썸네일 + 이름 + 상태 배지, 테두리 있는 정보 표, 들여쓴 ATC 경로, 제형별 접이식 카드, 아래 고정 줄의 큰 버튼 "관계 그래프 보기"(이미 그래프 탭이면 숨김).
- **휴대폰(≤699px)**: 작업 탭이 화면 맨 아래 막대(엄지 닿는 곳, 5개 모두 44px 이상) · 앱 막대 오른쪽 "분류" 버튼으로 트리 서랍 · 상세는 아래에서 올라오는 시트(손잡이, 위 모서리 20px, 높이 88% 이하, Esc/바깥 누르기/닫기로 닫음) · 가로 넘침 없음.
- **태블릿(700~1099px)**: 왼쪽 트리 + 가운데, 상세는 오른쪽 서랍. **노트북 이상(≥1100px)**: 3단. 카드 목록은 폭에 따라 1~3열(`auto-fill`), 본문은 최대 60rem(960px)에서 가운데 정렬.
- **"사진" 자리는 직접 그린 아이콘 타일**입니다(분류 4색 + 알약 그림 + 대분류 글자). 실제 사진은 쓰지 않았고 출처·저작권이 필요한 이미지는 넣지 않았습니다.
- **원본 템플릿 화면은 열어 보지 못했습니다**(Figma 무료 플랜의 보기 전용 좌석이라 파일을 읽을 수 없고, 임베드 주소는 사이트가 자동 열람을 막아 우회하지 않았습니다). 전달받은 설명(버튼·사진·카드 구성)을 바탕으로 만들었으므로, 원하는 화면의 캡처를 주시면 간격·카드 모양·버튼 배치를 더 가깝게 맞출 수 있습니다.
