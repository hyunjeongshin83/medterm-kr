MedTerm-KR React 화면(web-react) — 제3자 소프트웨어 고지문
생성: 2026-11-03 (tools/gen_notices.mjs, 실제 번들에 들어간 패키지만 자동 수집)

이 폴더의 dist/*.html 은 아래 오픈소스를 한 파일로 묶어 담고 있습니다. 각 라이선스 원문은 아래에 그대로 붙였습니다.
- 번들에 포함: @xyflow/react 12.12.1 (MIT), @xyflow/system 0.0.84 (MIT), classcat 5.0.5 (MIT), d3-color 3.1.1 (ISC), d3-dispatch 3.0.2 (ISC), d3-drag 3.0.1 (ISC), d3-ease 3.0.2 (BSD-3-Clause), d3-interpolate 3.0.2 (ISC), d3-selection 3.0.1 (ISC), d3-timer 3.0.2 (ISC), d3-transition 3.0.2 (ISC), d3-zoom 3.0.1 (ISC), react 18.3.1 (MIT), react-dom 18.3.1 (MIT), scheduler 0.23.2 (MIT), use-sync-external-store 1.7.0 (MIT), zustand 4.5.7 (MIT)
- 빌드 도구(결과물에 코드가 들어가지 않음): esbuild(MIT), Tailwind CSS 3.4.17(MIT). 단, 결과 CSS에는 Tailwind의 기본 리셋(preflight, MIT)과 React Flow의 base.css(MIT)가 포함됩니다.
- 글꼴: 공유 페이지 빌드(dist/artifact.html)는 Google Fonts의 Noto Sans KR(SIL Open Font License 1.1)을 링크로 불러오며 파일에 담지 않습니다. 독립 실행 빌드(dist/MedTerm-KR_react.html)는 글꼴을 담지 않고 시스템 글꼴을 씁니다.
- 데이터: 사전 내용(NLM RxNorm/RxNav 기반)과 분류 체계(ATC·SNOMED CT)의 이용 조건은 각 제공기관의 조건을 따릅니다. 이 고지문은 소프트웨어 부분만 다룹니다.
