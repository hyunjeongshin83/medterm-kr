4. 표시 문구 원칙 (디자인에도 적용)

  • "사전에 없음"은 환각이 아니라 확인 필요로 표시합니다.
  • "불일치 없음"은 정확하다는 뜻이 아니며 사전에 수록된 범위에 한한다고 함께 적습니다.
  • 한글명·상품명은 약사 검수 전 초안임을 표시하고, 단위용량은 미국 RxNorm 기준임을 표시합니다.
  • 진단·처방·개인별 복용량 판단을 하지 않으며 의사·약사 상담을 안내합니다(상단 면책 배너).

5. 디자인을 전달하실 때

  • 보내주시면 좋은 것: 화면 이미지(PNG·JPG·PDF), 색상·글꼴·간격 기준, 로고, 우선 구현할 화면 순서, 모바일 화면 여부.
  • 전달 방법: 채팅에 파일을 첨부해 주세요. Figma 등은 링크만으로는 열 수 없을 수 있으니 이미지·PDF로 내보내 주시면 확실합니다.
  • 반영 방식: 색·글꼴·간격은 index.html의 CSS 변수(:root)로 옮기고, 화면 레이아웃은 위 구조에 맞춰 적용합니다. 디자인과 현재 구조가 다르면 차이를 표로 먼저 정리해 확인받습니다.
  • 별도 페이지로 나눌지: 지금은 탭 방식입니다. 화면마다 주소(URL)가 필요하면 정적 페이지로 분리할 수 있습니다.
