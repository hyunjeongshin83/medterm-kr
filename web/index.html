MedTerm-KR 프로토타입

약무용어 전자사전 · 온톨로지(VTM→VMP→AMP) · LLM 답변 근거 검증 · 화면 구성 안내

정보 제공·연구용 프로토타입입니다. 진단·처방·개인별 복용량 판단을 하지 않으며, 한글명·상품명은 약사 검수 전 초안입니다. 복약 결정은 의사·약사와 상담하세요.
예: 메트포르민 · 노바스크 · C10AA · warfarin — 왼쪽 ATC 트리에서도 탐색할 수 있고, 선택하면 오른쪽에 상세가 표시됩니다.
관계 그래프 맞춤
왼쪽 분류 트리나 검색에서 성분을 고르면 관계가 표시됩니다.
실선은 성분 → 제형·용량(VMP) → 제품(AMP) 계층, 점선은 분류 관계(ATC 코드·상위 세부군·같은 세부군 성분)입니다. 파란 테두리의 성분과 ATC 노드는 눌러서 이동하거나 왼쪽 트리에서 찾을 수 있습니다(키보드: Tab, Enter).
"같은 세부군 성분"은 이 사전에 수록된 성분 안에서만 찾습니다(실제 같은 계열 약물 전체가 아닙니다). VMP·AMP는 미국 RxNorm 기준이고 한국 허가 제품(MFDS)은 아직 연동되지 않았습니다. 표시 개수에는 상한이 있어 일부는 "외 N개"로 줄여 표시하며, 전체 목록은 오른쪽 상세에 있습니다.

LLM 호출 (선택)

브라우저에 API 키를 두지 마세요. 서버(프록시/엣지 함수)의 URL만 입력하면 {system, user}를 POST하고 {text}를 받습니다. 비워 두면 아래 칸에 답변을 직접 붙여넣어 검증합니다.

상세 정보

왼쪽 트리나 검색 결과에서 성분을 선택하면 코드, ATC 경로, 제형·용량·제품 계층이 여기에 표시됩니다.
